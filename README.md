# Coffee Sales Dashboard — Tableau
Data analysis project visualizing coffee shop sales transactions using Tableau.
## Overview
Interactive dashboard built from a transactional coffee sales dataset, analyzing revenue, order volume, and customer payment behavior across time.
## Worksheets
- Total Sales
- Total Orders
- Average Order Value
- Monthly Coffee Sales Trend
- Peak and Off-Peak Revenue Hours
- Top-Selling Coffee Menu by Revenue
- Non-Coffee Sales by Time of Day
- Payment Method Distribution
